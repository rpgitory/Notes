Configuration commands
enable 					Enable privilege mode
Configure terminal 			Enable configuration global mode

interface GigabitEthernet 0/1		Configure an interface
 ip address 192.168.1.1 255.255.255.0
 no shutdown

vlan 10					Configure VLAN on a switch
 name IT_VLAN
show vlan brief or show vlan static

interface GigabitEthernet 0/2 		Assign a port to VLAN
 switchport mode access
 switchport access vlan 10

ip default-gateway 192.168.1.254 	Set up a default gateway on a switch

hostname Router01			Enable SSH access
ip domain-name example.com
crypto key generate rsa
ip ssh version 2
line vty 0 4

 login local

access-list 101 permit tcp 192.168.1.0 0.0.0.255 any eq 22 [Access Control List [ACL] to restrict access]

Cisco Switch Configuration Steps

Step 1: Set Hostname of switch 
Step 2: Set up Password
Step 3: Set up VLAN
Step 4: Set up ip address
Step 5: Set up DHCP 
[1-2]
en
config terminal
hostname "name"
enable secret Password123

[3]
vlan 10
name "name_vlan10 for employee"
vlan 20
name "name_vlan20 for regular guest"
interface gi1 [select port or ports] or interface range gi1/0/1-10
switchport mode access
switchport access vlan "name_vlan10 for employee" 		Access port can carry one vlan and trunk port can have multiple vlan

[4]
int vlan name_vlan10
ip address 192.168.10.1 255.255.255.0
no shutdown 
ip default-gateway 192.168.10.1 or .254


[5]
conf t [ go back here]
ip dhcp pool v10 [ can enter any pool name but suggested to go with vlan name so can identify]
network 192.168.10.0 /24 [ give ip for pool /24 or /16]
default-router 192.168.10.1 [ vlan IP or default gateway ip of VLAN]
